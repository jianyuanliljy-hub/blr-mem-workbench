# 秋季版接入与发布边界（2026-10-22）

## 来源和算法

默认核心源于作者提供的 `MEMECHO_2026秋季试用版/源码/023_0821.py`。原文件 SHA-256：`e1aafa352602d49324e4c4ef8c3fcd5ac6cc16937b7036132e4700445d9cd0b0`。适配后的副本保存在 `src/blr_rm/autumn/`；没有覆盖作者原应用目录。原 GitHub 名称、1D/2D 目录和数据协议保留。

流程：观测数据和误差同时按均值归一化 → 固定 C_bar → 对数坐标 Adam warm-up → 固定几何 default，联合优化 Psi/C，并条件求解各速度通道的正背景 → 分别检验三个参数块的 TEST 和相对 Q 梯度 → 对数阻尼更新 default → default 的 RMS 对数变化也达标才结束。输出还原物理单位。

目标是 mean(chi2_C) + mean(chi2_L) 减去三个 alpha 加权的归一化相对熵。每项熵除以其 default 总量。归一化降低尺度依赖，但不证明 alpha 完全与像素、采样、噪声或缺口无关。

一维是同一物理模型的单速度通道情形；单元素几何默认值有专门边界处理。拟合只读观测和元数据；truth.npz 仅供生成后检测和分析使用。NPZ 主流程要求规则连续谱输入网格，不会在缺口里伪造带误差观测。

## 本轮修复

- 补齐上传时遗漏的秋季核心源码，统一默认配置、扫描字段和 GUI 选项。
- 纠正旧扫描 `alpha` 与新 `alpha_map` 不适配问题；未知或旧参数必须显式选择 legacy，不能静默忽略。
- 修复原始程序的 alpha 环境参数传递、冻结运行资源路径、EXE CLI/GUI 参数分流。
- 背景 profile 已达到 float64 分辨率时，相对梯度比值可能放大舍入误差。只有逐通道 Newton 相对修正不超过 32 个 float64 epsilon 才视为数值静止；独立检测器用物理单位重新计算该条件，原始梯度仍保存。没有放宽 map/C 阈值。
- 默认固定 default 内层上限从 800 调至 2400，为困难样本留出预算；不是固定执行 2400 次，更不是把达到上限当成功。
- 旧二维 solver 修正重复目标计算、失败内层之后仍更新 default 的问题；它不是本版默认 solver。
- 清理错误放在 `.github/` 根下而不会执行的工作流副本；实际工作流只放在 `.github/workflows/`。
- 打包包含 JAX CPU、Numba、原始算法资源和独立入口。完整 EXE 操作验证在干净 PATH、无开发 PYTHONPATH 下运行。

## 使用限制

原生 Windows 没有打包 CUDA。GPU 为选择项，不承诺硬件不可用时加速；首次 JIT/Numba 编译的开销必须计入比较。小数据可能手写 NumPy 更快。纯扫描不自动依据跨 alpha 的 Q 选最优值。默认 alpha 只是示例设置。

`optimizer_success` 保存 SciPy 历次状态；科学收敛由独立 TEST、相对梯度和 default 稳定性判断。历史某轮 SciPy 警告与最终判据通过可以同时发生，不掩盖原始警告。严格不收敛样本保留为失败。

本版只对实际执行过的 Windows/CPU 测试做声明。大样本模拟、真实 AGN 验证、GPU 实测和普适 alpha 标定是不同层次的问题，不能用 GUI 能启动替代。
