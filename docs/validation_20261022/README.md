# 秋季版实际验证记录

本目录是本轮真实执行的固定协议实验，不是历史 GitHub 求解器的结果。

- 源码测试：69 项通过（Windows，Python 3.13.6）。
- 100×100 像素额外案例：默认手写梯度约 80.8 秒，独立前向、一阶收敛、default 稳定性均 PASS；shape NMSE 约 0.0838。单案例运行时间不是通用性能承诺。
- 模拟协议：144 组；一维 72/72 完成并通过，二维 66/72 完成并通过；6 例严格不收敛保留为失败。
- 配置在运行前固定：3 种传递函数形状 × 3 个噪声比例 × 2 个随机缺失比例 × 4 个独立种子，分别在两维运行。
- 所有完成案例的独立前向检查、一阶条件与 floating default 稳定性通过。SciPy 历次状态告警仍在统计中，不等于所有内层调用都 success。
- `protocol.json` 保存参数、实现指纹与环境；`per_case.csv` 保存全部案例；`summary.json` 包含失败原因、分母、误差和区间。
- 一维 shape NMSE 中位数约 0.00951；二维成功案例约 0.01173。二维指标只对完成的 66 例计算，不能忽略 6 例失败后声称全样本恢复率。
- 此协议使用随机发射线缺失，不是完整 seasonal gap 验证；也没有验证真实 AGN、GPU 或全局最优 alpha。

复现：从仓库根目录执行 `python tools/run_scientific_validation.py --out new_validation`。不同依赖、平台和 BLAS 舍入可能影响严格边界案例。EXE 操作验证另见发布包 `validation.json`，不与科学验证混为一谈。
